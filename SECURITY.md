# Security Policy

## Supported Versions

| Version       | Minecraft | Supported          |
| ------------- | --------- | ------------------ |
|   26.3-v0.1   |   26.3    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or multiplayer packet exploit in **Naruto-Mod**, please report it privately via GitHub Security Advisories on [Hamza-Zengin/Naruto-Mod](https://github.com/Hamza-Zengin/Naruto-Mod/security/advisories).
